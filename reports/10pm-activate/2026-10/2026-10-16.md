## 3. 问题与改动

**问题（真崩溃，非风格问题）**：`modules/postprocess/aurasr_arch.py` 的 `AuraSR.__init__` 默认 `device="cuda"`：

```python
class AuraSR:
    def __init__(self, config: dict[str, Any], device: str = "cuda"):
        self.upsampler = UnetUpsampler(**config).to(device)   # <-- 无 CUDA 的装机直接崩
```

任何**没有 CUDA 的装机**（纯 CPU 安装 / MPS / XPU / 昇腾 NPU）在构造阶段即崩：
`AssertionError: Torch not compiled with CUDA enabled`。

而调用方 `modules/postprocess/aurasr_model.py::UpscalerAuraSR.do_upscale` **本来就会自己放置模型**：

```python
self.model = AuraSR.from_pretrained("vladmandic/aurasr", use_safetensors=False)
devices.torch_gc()
self.model.upsampler.to(devices.device)     # <-- 加载后立刻搬到活设备
```

⇒ 这个硬编码的初始放置**既多余又致命**：非 CUDA 后端上「Aura SR 4x」这个上采样器根本选不了（不是跑得慢，是加载即崩）。

**修法（1 文件 +7/−4）**：`device` 默认改 `None`（模块留在 torch 创建它的地方，由调用方放置）；`from_pretrained()` 增加可选 `device` 透传。显式 `device="cuda"` 行为完全不变。

同项目另一处同类默认值 `pipelines/lens/transformer.py:132` 的 `device: torch.device = torch.device("cuda")`：**判为死默认**（仓内唯一调用点 `pipelines/lens/transformer.py:520` 显式传 `hidden_states.device`），改了没有实际收益且 fallback 语义不好写 ⇒ 本轮**不带**（已记入项目记忆，供以后判断）。
