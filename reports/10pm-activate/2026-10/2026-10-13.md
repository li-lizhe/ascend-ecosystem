### 问题（纯 Python 属性错误，非硬件解耦）

`layer.WSLinear.__init__` 用 `self.out_channels` 建可学习 gain，但 `WSLinear` 继承 `layer.Linear`(`nn.Linear`)，
只有 `out_features`、没有 `out_channels` ⇒ 默认 `gain=True` 时构造即崩：

```
AttributeError: 'WSLinear' object has no attribute 'out_channels'
```

`gain=False` 正常，所以默认路径一直没被发现。

后果是公开模型直接不可用 —— `OTTTSpikingVGG`（`weight_standardization=True` + `light_classifier=False`）的分类器
（`spikingjelly/activation_based/model/spiking_vggws_ottt.py:118`）用的就是 `layer.WSLinear`：

```
layer.WSLinear(4, 8)    -> AttributeError
ottt_spiking_vggws      -> OK（light_classifier=True，走 layer.Linear）
ottt_spiking_vgg11      -> OK
ottt_spiking_vgg11_ws   -> AttributeError
ottt_spiking_vgg13_ws   -> AttributeError
ottt_spiking_vgg16_ws   -> AttributeError
ottt_spiking_vgg19_ws   -> AttributeError
```

### 修法

`torch.ones(self.out_features, 1)` —— 与同文件 `WSConv2d`（`stateless_wrapper.py:1358` 的 `self.out_channels, 1, 1, 1`）写法对齐。1 行。
