## 六、对外留痕

### 6.1 commit message（已推送，head `a298758e`）

```
fix(cli): resolve the registry imports used by the config listing flags

`kernel-bench config --list-scoring-schemes` and `--list-checkers` are
documented argparse options, but their implementations import from modules
that do not exist:

- cli.py:987  from .report.scoring_scheme import ScoringSchemeRegistry
- cli.py:998  from .eval.checkers import list_correctness_checkers, get_checker_info

Neither module is present in the tree; both symbols live in the registry
package and every other caller in the repository already imports them from
there (e.g. benches/cann.py, eval/accuracy_eval.py, registry/__init__.py).
Because these are deferred imports inside cmd_config, the module still loads
and `--help` stays intact, so only users who actually run the two commands
see the failure - a ModuleNotFoundError and a non-zero exit code.

Point both imports at their canonical locations, and add a CLI-level
regression test that drives main() through the two flags so the branches are
exercised instead of only the registries themselves.

Signed-off-by: li-lizhe <147392333@qq.com>
```
